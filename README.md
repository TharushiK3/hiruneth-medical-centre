
# Hiruneth Medical Centre Management System

An internal web application for managing
the daily operations of Hiruneth Medical Centre.

## Core Features

- Patient registration and visit history
- Walk-in patient queue management
- Doctor attendance records
- Pharmacy inventory and expiry tracking
- Consultation and medicine billing
- Daily income and expenses
- Daily cash register with LKR 3,000 opening float
- Owner and assistant dashboards

## Technology Stack

- React + TypeScript
- Python + FastAPI
- PostgreSQL
